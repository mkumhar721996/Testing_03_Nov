## Decision

**Rule.** Unconfirmed defaults, not requirements: Scope: all backlog domains (slot game, patient health app, HR system, organization views, appliance-service marketplace) are built in one system on one Web App, one Application API and one database; overlapping epics are treated as the same capability.…

- Scope: all backlog domains (slot game, patient health app, HR system, organization views, appliance-service marketplace) are built in one system on one Web App, one Application API and one database; overlapping epics are treated as the same capability.
- Integration: Payment Provider (bidirectional)
